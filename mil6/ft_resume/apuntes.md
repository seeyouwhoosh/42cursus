## Vocabulario técnico
- **Machine Learning**: "is a subfield of artificial intelligence (AI) that uses statistical algorithms to let computers learn from data and make predictions or decisions without being explicitly programmed"
- **Machine Learning Pipeline**: Es básicamente la outline que conecta las diferentes tareas que tiene que hacer el modelo de machine learning, empezando por coger un archivo y todo el procesamiento de datos. Más o menos: recolección de data -> limpieza de datos -> exploratory data analysis -> selección de modelo -> entrenamiento de modelo -> tuneamiento de modelo -> usar el modelo -> monitoreo y mantenimiento
- **MLOps**: "Similar to DevOps or DataOps approaches, MLOps seeks to increase automation and improve the quality of production models, while also focusing on business and regulatory requirements. While MLOps started as a set of best practices, it is slowly evolving into an independent approach to ML lifecycle management"
- **AI model serving**: "is the process of making a trained machine learning or large language model (LLM) available in a production environment so external applications can send input data and receive predictions or generated text in real time"
